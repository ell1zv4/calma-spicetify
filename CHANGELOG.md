# Changelog

## 1.0.0 — 2026-11-17

First public release of Calma.

- Artwork-aware atmosphere, floating glass playback controls and a transparent library.
- Reversible single-image artwork flight with mouse Back support and bounded cancellation.
- One-time, visible-row song entrances and subtle playback feedback.
- Smooth collection header gradients and compact album, single and playlist layouts.
- Local settings for motion, audio previews, native view controls and an optional pinned playlist.
- Safe defaults: device motion preference, previews off, no personal playlist bundled.
- Responsive Home gallery, keyboard focus improvements and labeled generated cards.
- Optional ivLyrics integration; native middle-click is preserved without the app.
- Portable regression checks and a Marketplace manifest with a GitHub Pages script URL.
